# Validar con un profesional

Cosas que el sistema asume o diseña y que **no son asesoramiento legal ni
contable**. Antes de salir con usuarios reales (y, para lo contable, antes de la
etapa 0.2) las valida la persona que corresponda.

| Documento | Para quién | Cuándo |
|-----------|-----------|--------|
| [`contador.md`](contador.md) | Contador | Antes de la etapa 0.2 (POS e IVA) |
| [`abogado.md`](abogado.md) | Abogado | Antes de la etapa 0.5 (fiado) y antes de abrir a usuarios reales |

## Cómo se usa

- Cada pregunta tiene un estado: `pendiente` o `respondida`.
- Cuando se responde, se anota la respuesta con fecha, quién la dio y se actualiza
  el doc técnico afectado (Doc 1 o Doc 2).
- Lo que está escrito como "entiendo que…" es una **hipótesis nuestra**, no un hecho.
- Pasar a un profesional: este archivo se puede imprimir o mandar tal cual.
